# 壳界面重设计

> 状态：**已按本设计实现**（`app/` 的布局、`KnobActivity.kt`、`LogSink.kt`，插件页面的深色样式在 `api/Ui.kt`），两个壳变体和插件都编译通过；**没在车机和手机上看过实际效果**，壳要重新用车机厂商签名签过才能装车。

设计稿在 Claude 的设计画布上（私有链接，需要分享才能给别人看）：<https://claude.ai/artifact/G3WSd7vWmk5pube1r7xSmY>。画布上有车机宽屏 4 种状态（插件已加载 + 日志展开、日志收起、还没导入插件、启动自检没通过）、手机竖屏、车机半屏两种状态、按宽度分档规则和规格。

## 相对旧界面改了什么

| 旧界面的问题 | 新设计 |
|------|------|
| 日志和插件各占半屏，日志抢了一半地方 | 插件区是主体，放左边（离驾驶员近）；日志是右侧 400dp 的面板，可收起 |
| 浅色主题，跟旋钮屏的深色仪表风格不搭；车机深色模式下还得防反色 | 固定深色主题，颜色跟旋钮圆屏同一套（见下面「颜色」），不跟系统深浅色切换 |
| 三个 emoji 大按钮 + 一行蓝牙权限按钮 | 顶栏：左边两个状态胶囊（插件加载了没有、导入时间；蓝牙权限），右边「导入插件」「日志」两个按钮。清空 / 保存日志挪进日志面板 |
| 蓝牙权限是一个常驻的大按钮 | 蓝牙胶囊没授权时变红、带「授权」，点它申请；授权后变回普通胶囊、不可点 |
| 日志是一整块灰字，错误淹没在里面 | 按级别上色（✅ 绿 / ⚠️ 琥珀 / ❌ 红），可以只看警告和错误；面板收起时，最新一条显示在顶栏，「日志」按钮上有红色角标数没看过的错误（界面在后台期间来的也算）。启动时的平台权限清单先一行汇总，明细只算普通信息——很多 GET/SET 车机上根本不存在，按错误算的话一开机角标就是几十 |
| 往上翻日志会被新日志拽回底部 | 往上翻时自动滚动暂停，出现「回到最新」；面板头上的按钮也能开关自动滚动 |
| 没导入插件时插件区只有一个 emoji 占位 | 三步说明（拷 U 盘 → 导入 → 自动加载并升级旋钮）+ 大的「导入插件」按钮 |
| 按 `sw600dp`（最小宽度）分横竖两份布局 | 按窗口宽度分两档（见下），车机分屏的半屏也能用 |

## 按窗口宽度分两档

比亚迪车机支持左右对半分屏，分屏时 Knob 的窗口只有半个屏幕宽：1280dp 的屏是 640×720dp。旧布局按 `sw600dp`（最小宽度）判断，半屏时最小宽度 640 仍然 ≥ 600，会套用左右各半的宽布局，插件只剩 320dp。现在按宽度分：

| 窗口宽度 | 布局文件 | 样子 |
|------|------|------|
| ≥ 960dp（车机全屏） | `res/layout-w960dp/activity_knob.xml` | 顶栏胶囊带文字、按钮带文字；日志是右侧面板，收起后最新一条在顶栏 |
| < 960dp（车机半屏、手机） | `res/layout/activity_knob.xml` | 胶囊只写「插件」「蓝牙」，导入按钮只留图标；日志收成底部一条（最新一条 + 未读错误数），点开是盖住插件区下半部分的抽屉，返回键 / 点遮罩 / 收起按钮关掉 |

- 两份布局的控件 id 一致，日志面板（`layout/log_panel.xml`）和空状态（`layout/plugin_empty.xml`）两边 include 同一份；只在一边有的控件（`btnLog`、`logStrip`、`logScrim`）在 ViewBinding 里是可空的，`KnobActivity` 用 `isWide` 区分。
- 进出分屏窗口大小一变，Activity 会重建：插件靠 `ui.unbind` / `ui.bind` 跟着重绑，插件状态和旋钮连接不受影响；宽布局的日志面板开合存在 SharedPreferences（跨启动记住），窄布局的抽屉只在重建时恢复。
- 每次 Activity 创建都会记一行 `窗口 W×Hdp，密度 D，分屏=是/否，布局=宽/窄`，装车后全屏、半屏各看一眼就知道系统实际给了多大的窗口。
- 车机分屏时应用列表里能不能选到 Knob：壳的 manifest 没写 `resizeableActivity`，targetSdk 34，按标准 Android 默认支持分屏。比亚迪有没有另外的筛选规则，网上查不到官方说明，要上车看。

## 插件页面的深色

`api/Ui.kt`（壳和插件两份一致）换成了深色样式，尺寸按 dp 算，新增 `primaryBtn`（蓝色主按钮）和 `COLOR_OK` / `COLOR_WARN` / `COLOR_ERROR` 等颜色。插件运行时用的是壳里那份 `Ui`（父加载器优先），所以**新插件要配新壳**：配旧壳会出现浅底白字，新加的方法还会 `NoSuchMethodError`，这一点不做兼容。插件页面结构没动，只换了颜色和尺寸，确认 / 提交 / 申请这类按钮用主按钮，温度和座椅档位的读数放大了。

## 颜色

跟旋钮圆屏同一套，定义在 `app/src/main/res/values/colors.xml`（插件页面用的同值写在 `api/Ui.kt`）：

| 用途 | 颜色 |
|------|------|
| 窗口底色 | `#0A0C0F` |
| 插件区 / 插件页面底色 | `#12161B` |
| 顶栏、日志面板 | `#0F1216` |
| 次要按钮 / 边 | `#1A1F26` / `#2B313A` |
| 主按钮 | `#2563EB` |
| 按下的开关按钮（底 / 边 / 字） | `#15233A` / `#2D4D82` / `#A9C4F5` |
| 主文字 / 正文 / 次要文字 | `#F2F4F7` / `#C9CED6` / `#8A93A0` |
| 成功 / 警告 / 错误（深底上的错误字） | `#34D399` / `#F7C948` / `#F0414D`（`#FF7A82`） |

触控目标不小于 44dp，车控主按钮 48dp 起。设计稿里用了 Barlow Semi Condensed（数字）和 JetBrains Mono（日志），实现里先用系统字体（`sans-serif-condensed`、`monospace`），没有往壳里打包字体。
